# Password Generator

A simple Command Line Interface (CLI) Python script that generates strong, randomized passwords based on user-specified numbers of letters, digits, and symbols.

## Features

* **Customizable Length**: Choose exact counts for letters, numbers, and special characters.
* **Randomized**: Uses Python's standard `random` module to shuffle characters for enhanced randomness.

## Requirements

* Python 3.x installed on your system. No external dependencies are required.

## How to Run

1. Clone or download this repository.
2. Open your terminal or command prompt and navigate to the project directory.
3. Run the script:
   python main.py
